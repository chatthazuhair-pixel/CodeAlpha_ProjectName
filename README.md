# CodeAlpha Python Programming Internship

This repository contains the Python projects I completed during my **CodeAlpha Python Programming Internship**.

For this internship, I focused on building small but practical Python applications while improving my understanding of programming logic, functions, loops, conditionals, user input, and Streamlit.

## 🚀 Projects

### 🎯 1. Hangman Game

A simple Hangman game where the player tries to guess a hidden word one letter at a time.

The game randomly selects a word and keeps track of guessed letters and wrong guesses. The player gets a maximum of **6 wrong guesses** before the game ends.

I also created a Streamlit interface so the game can be played directly in a web browser.

**Live Demo:**  
[🎮 Play Hangman](https://codealphaprojectname-sajsxnsvy7knsrexy8t3wz.streamlit.app/)

**Folder:** `Hangman_Game/`

---

### 📈 2. Stock Portfolio Tracker

A simple stock portfolio tracker that calculates the value of an investment based on the stock symbol and quantity.

The program uses a predefined dictionary of stock prices and calculates:

`Stock Price × Quantity = Investment Value`

I also created a Streamlit interface for using the tracker through a web browser.

**Live Demo:**  
[📊 Open Stock Portfolio Tracker](https://codealphaprojectname-j8lo5bv3wgdgwg8apbfu9f.streamlit.app/)

**Folder:** `stock-tracker/`

## ▶️ Running the Projects Locally

Install the required packages from the relevant project folder:

```bash
pip install -r requirements.txt
```

Then start the Streamlit application:

```bash
streamlit run demo.py
```
